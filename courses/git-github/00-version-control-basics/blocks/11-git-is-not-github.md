---
type: Warning
title: Git is not GitHub
---

Git is a version control tool that runs on your computer. GitHub is a company and website that hosts Git repositories and adds collaboration features such as issues, pull requests, and actions.

You can use Git without GitHub. A repository on your laptop, a self-hosted server, GitLab, or Bitbucket all work without GitHub. You can also browse and edit files on GitHub, but the underlying history is still Git.

Do not treat the names as interchangeable, and do not assume GitHub is a backup. A local repository with no remote exists in one place. A GitHub repository is a copy that can be deleted, made private, or become unavailable. Keep another copy if the history matters.
