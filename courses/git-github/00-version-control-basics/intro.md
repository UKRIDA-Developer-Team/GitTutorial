You need a terminal where you can run commands, and Git installed on your computer. Check the installation with:

```bash
git --version
```

If the command is not found, install Git from [git-scm.com/downloads](https://git-scm.com/downloads). If `cd`, `ls`, and `dir` are unfamiliar, work through the shell course first.

You do not need a GitHub account for this chapter. Git is the version control tool; GitHub is a hosting service for Git repositories. You will set your Git name and email in a later chapter, before your first commit.
