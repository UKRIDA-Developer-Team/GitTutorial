![A local repository and a remote repository. git push sends commits to the remote; git fetch downloads commits from it; git pull combines fetch with a merge into the current branch.](../media/blocks/local-and-remote/local-and-remote.svg)

The local repository contains your branches and history. The remote is another copy that you synchronize with push, fetch, and pull.
