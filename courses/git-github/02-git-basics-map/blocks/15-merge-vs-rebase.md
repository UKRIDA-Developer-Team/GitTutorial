![Two diagrams. Merge joins main and feature with a merge commit that has two parents. Rebase replays the feature commits onto the tip of main, creating new commits in a straight line.](../media/blocks/merge-vs-rebase/merge-vs-rebase.svg)

Merge keeps both lines of history and adds a merge commit. Rebase creates new commits on top of a new base.
