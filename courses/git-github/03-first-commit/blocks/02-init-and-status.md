---
type: Commands
title: Create a repository and inspect it
---

| Command | What it does |
| --- | --- |
| `git init` | Create a Git repository in the current folder |
| `git status` | Show the current branch and the state of files in the working tree and index |

Run `git init` once in the project folder. It creates a hidden `.git` directory, which is the repository. The folder itself becomes the project's working tree.

`git status` is the command you will run most often. It reports the branch, whether there are commits yet, and which files are untracked, modified, or staged.
