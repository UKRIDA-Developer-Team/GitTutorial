This chapter explains how Git and GitHub decide who you are. It uses the GitHub CLI, `gh`, where a command exists. GitHub's website can perform the same account setup, and other formats of this course may show the web interface.

The examples assume Git and `gh` are installed. Chapter 07 covers remotes and pushing; this chapter explains why a push can fail even when the remote exists and the branch is correct.

Authentication is not the same as permission. A credential proves which account is acting. The repository decides what that account may do.
