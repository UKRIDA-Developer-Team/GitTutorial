This chapter explains forks: separate repositories that let you contribute when you do not have write access to the source. It uses the GitHub CLI, `gh`, where a command exists. GitHub's website can perform the same actions, and other formats of this course may show the web interface.

The examples assume chapters 07 and 08: you can clone, push, and open a pull request. A fork is a platform feature, not a Git command, so the Git sandbox practices the branch and remote operations rather than creating a real fork.
