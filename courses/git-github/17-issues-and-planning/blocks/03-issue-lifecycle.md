![An issue moves from open to triage, then to a linked branch and a pull request, then to merge and closed. A dashed reopen path returns from closed to open.](../media/blocks/issue-lifecycle/issue-lifecycle.svg)

The issue tracks the work from report to merge. The branch, commits, and pull request carry the code; the issue carries the plan and the record of decisions.
