This chapter explains how teams gate merges when many people and many pull requests share a branch. It uses the GitHub CLI, `gh`, to inspect rules and pull request state. GitHub's website configures the same rules, and other formats of this course may show the web interface.

The examples assume chapters 08 and 17: pull requests, reviews, checks, and issues are already familiar. Rulesets, CODEOWNERS, and merge queues are platform features; they are not Git objects and are not simulated by the Git sandbox.
