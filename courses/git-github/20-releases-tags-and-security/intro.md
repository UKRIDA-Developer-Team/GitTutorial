This chapter explains how a tested commit becomes a published release, and how signing and scanning support that release. It uses the GitHub CLI, `gh`, for releases and Git for tags. GitHub's website performs the same release actions, and other formats of this course may show the web interface.

The examples assume chapters 02, 08, and 19: tags, pull requests, and CI are already familiar. A GitHub Release is a platform object around a Git tag. The Git sandbox practices tags and history; it does not publish releases or run security scans.
